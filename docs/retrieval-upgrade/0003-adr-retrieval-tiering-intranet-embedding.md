# ADR 0003：检索三级分层与内网 Embedding 服务（草案，待批准后移入 docs/adr/）

- 状态：Proposed（2026-10-23，Phase 0 交付物）
- 决策人：知识库负责人（2026-10-23 会话裁决）
- 影响范围：检索引擎、init/doctor、遥测指标、团队推广形态

## 背景与动机

1. 真实库实测（2026-09-17 基线，tests/test_retrieval.py）：关键词查询 8/8 命中，**同义口语改写 0/4**，HitRate@3 = 8/12。词法层（FTS5 trigram + LIKE + 4 条硬编码别名）无法覆盖"换个说法描述同一故障"。
2. 2026-10-23 实测归因：UserPromptSubmit hook 把整段用户输入当查询（hooks.py:82），3648 字长文经 **lexical 与 dense 双通道**共同产生无关注入（DB 副本重放证实，命中卡 channels=['lexical','dense']）——既有噪音问题不是单通道缺陷。
3. 代码现状：混合检索骨架（RRF 融合 index.py:315、embedding_index 表含 model_version/content_hash index.py:45-47、dense 通道 index.py:266）**已建成但向量是字符 n-gram 哈希冒充的**（index.py:249，注释自认"不冒充语义模型"）；`model_version` 只写不读（index.py:273 读取不过滤），裸换模型必然混合向量空间。

## 决策

1. **Embedding 来源：公司内网 OpenAI 兼容 API 为唯一首期 Provider**。禁止外部公共模型服务作为默认依赖；首期不安装本地 ONNX、PyTorch、Reranker、独立向量数据库。
2. **此前"本地 ONNX（fastembed/BGE）"路线取消**（2026-10-23 当日早期裁决被本 ADR 覆盖）。`local_onnx` 仅作为 Provider 接口的**未来扩展点保留枚举位，不实现**——ONNX 涉及模型分发、依赖管理、OS 适配、生命周期治理，在内网服务已具备的条件下按"不为可能的未来提前建设"原则推迟，出现真实离线需求再立项。
3. **三级自适应检索**：L3（FTS5+真向量+RRF）/ L2（规则化同义扩展+FTS5）/ L1（FTS5+短词 LIKE 回退）。`mode: auto` 自动升降级；任何等级都允许返回零结果；字符哈希 dense 通道不得作为任何等级的语义替代。
4. **Hook V1 运行策略**：UserPromptSubmit 自动检索不调用远程 Embedding（一次性进程无法持有熔断态 + 同步网络尾延迟 + 注入污染代价）。此为**部署策略配置**（`retrieval.auto_hook_semantic=false` 默认），不写死在检索引擎——未来集中式低延迟检索服务出现时可评估放开。
5. **产品承诺**：`knowbase init` 一条命令接入；不配置模型完全可用；模型只决定检索能力上限，不决定可用性。

## 依据与替代方案

| 替代方案 | 不采用原因 |
|---|---|
| 本地 ONNX（BGE-small） | 单版本运行时零 ML 依赖（现状 pyproject 仅 10 个纯 Python 依赖）；团队成员机器适配与模型分发成本高；内网服务已具备 |
| 纯向量检索 | 错误码/类名/版本号等精确标识词法层更可靠（HTTP 401 vs 403） |
| Reranker | CPU/网络成本与 172 张卡规模不匹配，暂缓（Phase 2 后依数据重议） |
| sqlite-vec | pre-v1 兼容风险；当前规模纯 Python 点积足够 |

## 后果

- 正面：零配置可用与可选增强解耦；冷启动问题消失（HTTP 无模型加载）；评测结论可直接迁移（向量来自生产同源服务）；推广不依赖个人硬件。
- 负面/代价：查询文本出本机进内网服务（内网边界内，需在接入手册声明）；"完全本地"从保证降为默认形态；新增网关治理问题（别名换底座）——由 03 号设计的模型指纹+多维 canary 探针应对。
- 不可逆点：embedding_index 需引入按 model_version 隔离的读取过滤与增量更新；旧字符哈希向量标记退役而非混用。

## 验证门槛（本 ADR 生效后的退出条件）

Phase 2 上线前提：五组对照实验（06 号文档）证明 C/D/E 相对 A/B 有实际收益且 must 类 8/8 不回退；无关注入率与正确拒绝率达到门槛。未通过则 L3 不进入生产，方案回退为本 ADR 重新评审。
