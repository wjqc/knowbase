# 06 · 五组对照实验协议与验收门槛（Phase 0 设计，Phase 1/2 执行）

## 1. 实验组定义

| 组 | 查询输入 | 检索方式 | 门控 | 验证目标 |
|---|---|---|---|---|
| A 基线 | 原始查询 | 现状混合（lexical+char-ngram dense+RRF） | 现状行为（无门控） | 生产 rc6 行为复现 |
| B 蒸馏 | 查询卫生后（02 号§5 规则） | 同 A | 现状行为 | 蒸馏独立收益 |
| C 语义 | 原始查询 | FTS5+真向量+RRF | 无 | "换模型不治脏查询"的量化证明 |
| D 混合增强 | 蒸馏后 | FTS5+真向量+RRF | 无 | 模型+蒸馏联合收益 |
| E 完整 | 蒸馏后 | FTS5+真向量+RRF | 分模式校准门控 | 拒绝无关的最终形态 |

- A/B 可立即跑（纯本地）；C/D/E 依赖向量缓存（05 号§4），**必须使用拟投产的内网模型**——本地 BGE 结论不迁移（ADR 0003）。
- 全部组共享同一评测集、同一排序因子、同一 scope 过滤；差异仅限查询预处理/通道/门控三变量。

## 2. 指标

| 指标 | 定义 | 主看层 |
|---|---|---|
| Recall@5 / MRR@10 | relevant_ids 命中与排序 | 可回答样本 |
| Precision@3 | 前三相关占比 | 常规命中+精确标识 |
| 无关自动注入率 | 注入条目中不相关占比 | 长文负例+短模糊 |
| 正确拒绝率 | 应空样本中返回空的比例 | unanswerable+长文负例 |
| must/gap 通过率 | golden set 口径 | 全体 |
| p95 延迟 | 离线测引擎耗时；hook 端到端单独测 | 全体 |
| Token 开销 | 注入字符/2 估算 + 模型调用 token（缓存场景=0） | 全体 |

**核心对外指标：无关自动注入率、平均注入 Token**（直接关联推广价值叙事）。

## 3. 验收门槛（建议值，待负责人批准后冻结）

Phase 1（B 组上线）：
1. 长文负例无关注入率：A→B 下降 ≥80%（现状近乎 100% 注入）；
2. golden must 8/8 不回退；常规命中 P@3 不低于 A；
3. hook 路径 p95 延迟增幅 ≤20ms（纯规则，预期 <5ms）。

Phase 2（D/E 组，L3 准入）：
1. gap 类 HitRate ≥ 3/4（基线 0/4，tests/test_retrieval.py 口径）且 must 8/8 不回退；
2. D 相对 B：Recall@5 提升 ≥10 个百分点（可回答样本）；
3. E 相对 D：无关注入率再降 ≥50%，正确拒绝率 ≥85% 且可回答样本 Recall@5 回落 ≤3 个百分点（门控的精度/召回交换边界）；
4. 零命中误杀率：E 组对常规命中层错误返回空的比例 ≤5%；
5. L3 在线 p95（含一次远程 embed）：≤800ms（**待内网实测后定稿**），降级不产生用户可见错误。

未达门槛：对应能力不进生产（Phase 2 出口关闭），回归实验定位后重测；两次不达标注销重审。

## 4. 门控阈值校准方法（E 组前置）

- 用标注集正负样本画每模式（L3 dense 余弦、L2 lexical 分、RRF 融合名次）的 ROC，取"拒绝 90% 负样本时的召回"对应分位为初始门槛；
- 门槛写入 config（02 号§6），随 `gate` 键可调；校准过程与图存 `eval/gate-calibration.md` 供复核；
- 禁止直接搬用 dense_threshold=0.25（char-ngram 校准值，量纲不兼容——01 号§5）。

## 5. 执行约束

- 只读生产库副本（`.backup` 到临时目录，2026-10-23 会话已验证该流程）；
- rc6/rc7 基线差异：A 组须分别以生产 rc6 与待发 rc7 各跑一次，冻结 rc7 为正式基线（01 号待验证项 3）；
- 实验代码与脚本入本工作区 `experiments/`（Phase 1 建），不进生产运行时；
- 所有结果表含样本量与置信区间（小样本用精确二项），不报无区间百分比。
