# ADR 0005：独立定时升级器与稳定 MCP 入口

日期：2026-10-26。状态：已实现并在本机隔离环境验证；真实成员、Windows/Linux调度与各宿主缓存行为待验证。

## 问题

知识Git同步能交换Markdown，却不会替换成员电脑上的Python运行包。统计门禁修正等程序变更不能仅靠发布者推送知识仓库传播。已有MCP长连接还会继续持有旧模块；由旧worker自行卸载/杀死自己无法保证崩溃后恢复。

## 决策

成员一次明确授权独立的程序Git源后，使用OS原生定时任务启动包外的标准库更新入口。暂存构建、影子数据验证和备份先完成，再排空旧调用，原地替换唯一固定环境。MCP宿主连接交给稳定代理，后端随更新切换并内部初始化；Hook维护期静默记录显式补采引用，无材料则留缺口。持久安装日志由下一次独立任务优先恢复。

不从知识仓库推断程序源，不覆盖成员源码工作区。不保留运行包副本或旧wheel；恢复时从本地Git历史临时重建旧包。数据与配置备份独立保留。依赖集合变化、协议破坏、不可安全恢复的台账迁移不自动放行。

## 取舍与边界

增加一个小型稳定协议层，换取宿主不必每次手动重连。初次从旧直连入口迁移仍需重连一次；宿主缓存的系统说明仍可能到新会话才刷新。稳定入口协议本身变化要显式迁移，不能宣称修改文件即改变已运行代理。

定时检查是最终一致，不保证离线电脑立即更新；失败退避，真实网络/权限由成员环境提供。源码分支是明确的执行信任边界，发布者须先回归再推送。检索、模型、统计收集与程序更新分别报告，程序安装成功不等于统计补报或业务收益验收。

实现、命令、失败状态与本地验证范围见[无人值守升级说明](../program-auto-update.md)。
